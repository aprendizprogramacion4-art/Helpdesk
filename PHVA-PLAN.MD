# HelpDesk

## Project Objective
Build a web application for managing technical
support requests using Laravel.

## User Roles
- Requester
- Technician
- Administrator

## Main Features
- User authentication
- Ticket creation and tracking
- Priority management
- Technician assignment
- Comments and status history
- Automated testing

## PHVA Cycle
### Plan
Define requirements and acceptance criteria.

### Do
Implement the application features.

### Verify
Execute manual and automated tests.

### Act
Fix defects and verify improvements.
